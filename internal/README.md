# Documentos internos

Este directorio guarda documentación de trabajo del repositorio: auditorías, planes temporales, notas de reorganización y otros artefactos que sirven para mantener el proyecto, pero que no forman parte de la documentación estable del plugin.

Regla simple:

- `docs/` contiene documentación técnica útil y relativamente estable para entender, usar y mantener Alfred Dev.
- `internal/` contiene documentos temporales o de gestión interna que no deben mezclarse con la superficie documental del plugin.
